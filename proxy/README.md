# REST API Proxy

Учебный HTTP-прокси для REST API задач на Go. Прокси принимает запросы на порту `8090` и
пересылает их API, запущенному на `http://localhost:8080`.

## Запуск

В одном терминале запустите основной API на порту `8080`, затем в папке этого проекта выполните:

```powershell
go run ./proxy
```

Прокси будет доступен по адресу `http://localhost:8090`.

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/tasks` | Получить список задач и query-параметры |
| `POST` | `/tasks` | Создать задачу |
| `GET` | `/tasks/{id}` | Получить задачу |
| `PUT` | `/tasks/{id}` | Обновить задачу |
| `DELETE` | `/tasks/{id}` | Удалить задачу |

Прокси передаёт JSON-тело запросов `POST` и `PUT`, а также статус и тело ответа API. При
недоступности API возвращается `502 Bad Gateway`.
